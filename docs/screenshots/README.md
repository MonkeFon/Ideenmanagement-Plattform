# Screenshots

Captured from the running application against the seeded demo data. Signed in as the **FOM Ideenmanager** (`lifon@fom.de`) unless noted; the **Administration** and **multi-tenancy** shots use the **Globex Administrator** (`owner@globex.test`). The colour scheme follows the tenant — **FOM** is teal `#239F91`, **Globex** is indigo `#4f46e5`. Light mode unless noted. Generated by driving headless Chrome (Playwright) over the running dev stack (`:5173` + `:8080`).
